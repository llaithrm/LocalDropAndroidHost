# LocalDrop Android Host — الإصدار الأولي 0.1

مشروع Android Studio موجّه إلى Samsung Galaxy S8+ بنظام Android 9 (API 28)، دون Root.

## الموجود في هذه النسخة
- تطبيق Android أصلي مع تشغيل/إيقاف السيرفر.
- سيرفر HTTP محلي على المنفذ 8765.
- رمز دخول محلي من 6 أرقام يظهر على شاشة الهاتف.
- طلب موافقة MediaProjection وبث الشاشة كإطارات JPEG.
- استقبال أوامر tap وswipe/scroll عبر AccessibilityService.
- صفحة ويب واحدة تعمل من متصفح Windows وSafari على iPhone.
- واجهات أولية للمحادثة، الملفات، وقائمة الأجهزة.

## خطوات الفتح والتجربة
1. افتح المجلد في Android Studio (Giraffe أو أحدث).
2. اسمح لـ Gradle بتنزيل Android Gradle Plugin وNanoHTTPD.
3. ثبّت التطبيق على S8+.
4. افتح التطبيق واضغط «تشغيل السيرفر».
5. فعّل خدمة التحكم من زر Accessibility، ثم فعّل LocalDrop Android Host من إعدادات تسهيلات الاستخدام.
6. اضغط «السماح ببث الشاشة» ووافق على نافذة Android.
7. أدخل عنوان IP الظاهر في التطبيق من Windows أو iPhone: `http://PHONE-IP:8765`
8. أدخل رمز الدخول المعروض في التطبيق.

## حدود معروفة في 0.1
- هذه نسخة تأسيسية وليست بديلًا مكافئًا مكتملًا لكل وظائف LocalDrop Pro على Windows.
- بث الشاشة يعتمد polling لإطارات JPEG، وليس WebRTC؛ لذلك قد يظهر تأخير واستهلاك أعلى للشبكة.
- عناصر النظام المحمية، شاشة القفل، نوافذ الصلاحيات وبعض التطبيقات الحساسة قد تمنع التحكم أو إظهار المحتوى.
- إدخال النص عبر IME/لوحة مفاتيح النظام غير مضاف بعد.
- المحادثة وقائمة الأجهزة في هذه النسخة داخل الذاكرة وتُفقد عند إيقاف الخدمة؛ لا توجد بعد قاعدة SQLite دائمة أو مزامنة متكاملة.
- واجهة إدارة الملفات أولية. رفع الملف يعتمد multipart، والتنزيل يحتاج رمز الدخول في رابط التنزيل.
- يلزم اختبار فعلي على S8+؛ لا أستطيع الادعاء ببناء APK أو اختبار الجهاز من هذه البيئة.

## ملاحظات أمان
استخدمه على شبكة موثوقة فقط. رمز الدخول يحدّ من الوصول لكنه ليس تشفيرًا؛ حركة HTTP داخل الشبكة غير مشفرة. لا تستخدمه عبر الإنترنت أو شبكة عامة.

## إنشاء APK دون Android Studio

1. فك ضغط المشروع، ثم ارفع **محتويات المجلد** إلى مستودع GitHub جديد.
2. اجعل اسم الفرع `main`، وتأكد أن ملف `.github/workflows/android.yml` موجود.
3. افتح تبويب **Actions** في المستودع.
4. اختر **Build LocalDrop Android APK** ثم **Run workflow** (أو انتظر اكتمال البناء بعد رفع الملفات).
5. افتح عملية البناء الناجحة، ومن قسم **Artifacts** نزّل `LocalDropAndroidHost-debug-apk`.
6. فك ضغط الملف المنزّل؛ ستجد `app-debug.apk`. انقله إلى الهاتف وثبّته بعد السماح بالتثبيت من هذا المصدر.

هذا ينتج APK تجريبيًا من نوع Debug، وليس إصدارًا موقعًا للنشر. يجب مراجعة المشروع واختباره على الهاتف قبل الاعتماد عليه. يتطلب بث الشاشة موافقة MediaProjection، ويتطلب التحكم باللمس تفعيل خدمة إمكانية الوصول يدويًا.
